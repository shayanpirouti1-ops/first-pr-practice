# first-pr-practice

A tiny practice repo with a couple of small utility functions, used to
practice the GitHub PR workflow: branch, commit, push, open PR, merge.

## Usage

```python
from utils import add, multiply

add(2, 3)       # 5
multiply(2, 3)  # 6
```

## Tests

Run the tests with:

```
python -m unittest discover tests
```
